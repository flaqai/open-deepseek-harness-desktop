## 维护规则

- schema 6 新版本必须记录翻译源语言，并分别记录四项公开文案的页面比较结果、用户确认的继承或覆盖决策、保存与回读状态。
- schema 6 的描述列记录最终策略，例如 `replace_after_user_confirmation` 或 `inherit_after_user_confirmation`；schema 1–5 历史行保留其原策略。
- 本地化范围覆盖 App Store Connect 当前的已本地化和未本地化语言。
- 单元格只记录状态和非敏感公开值；不复制长文案、账号、密码、电话、Token 或签名材料。
- 字段没有单独授权时记录继承，不得顺手修改。
