# App Store ASO Audit Framework

## Evidence Inventory

Record the App Store URL, storefront, locale, access date, visible metadata, screenshot/preview sequence, supplied metrics, experiment history, inspected competitor URLs, and unavailable/private evidence.

## Scorecard

Score each area from 0 to 5 only to prioritize work:

| Area | Question |
| --- | --- |
| Positioning | Is the audience, job, and differentiator clear? |
| Relevance | Do metadata and visuals match observed user intent? |
| Credibility | Are claims supported by visible product evidence? |
| Metadata quality | Is copy specific, readable, compliant, and localized? |
| Visual narrative | Do early assets communicate outcome and progression? |
| Experimentability | Is each proposed change isolated and measurable? |

The score is not an Apple ranking score. State what evidence would change it.

## Competitor Matrix

Compare only observed page data:

| App | Positioning | Metadata promise | First three asset messages | Proof | Opportunity |
| --- | --- | --- | --- | --- | --- |

Do not copy competitor trademarks into Keywords. Apple disallows names of other apps or companies there.

## Recommendation Format

For each recommendation include the proposed change, observed problem, source or inference label, expected user mechanism, effort/dependencies, success metric/guardrail, and an experiment stopping rule when data exists.

## Evidence Gaps

List missing evidence explicitly, for example: public pages do not expose Keywords, product-page analytics were not supplied, a competitor storefront could not be accessed, or screenshot source files are unavailable. Never convert a gap into an invented fact.
