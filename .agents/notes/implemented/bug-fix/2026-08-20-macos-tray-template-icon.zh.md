# Agent Note: 为 macOS 托盘提供专用模板图标

Status: implemented

[English](2026-08-20-macos-tray-template-icon.md) | 中文

## 问题

桌面宿主把完整的 1024 像素应用图标缩小后标记为 macOS 模板图。由于圆角方形背景并不透明，macOS 会把整个方块转换成单一的菜单栏颜色，最终显示成纯白按钮，而不是应用标志。

## 决策

macOS 改用根据应用“人骑鲸鱼”轮廓绘制的黑色加透明通道 `tray-iconTemplate.png`。渐变底图被省略，人物则简化为分离的头部与紧凑骑坐姿态，使其在菜单栏尺寸下仍可辨识。图形会尽量占满图片边界，使状态项分配范围与可见标志相匹配。源 SVG 让经过视觉居中的小尺寸几何可以维护，16 像素 PNG 与 32 像素 `@2x` PNG 遵循 Electron 的模板图命名与密度约定。Windows 和 Linux 继续使用完整的彩色应用图标。

## 考虑过的替代方案

**继续缩放完整应用图标。** 不透明的圆角方块会变成实心模板轮廓，无法在菜单栏形成可辨识的标志。

**使用未经简化的详细骑鲸人物图。** 细小的内部形状会在 16 像素下塌缩，同时留下过多透明边距，使状态项显得更小且视觉上不居中。

## 验证

桌面资源构建会复制两个密度的模板 PNG，且不会改名。基础资源为 16×16 RGBA，有效边界为 16×14；Retina 资源为 32×32 RGBA，有效边界居中且为 30×28。两者都保留透明背景。桌面类型检查与桌面构建验证消费路径。

## 后果

菜单栏图标会适配系统明暗外观，并在原生状态栏尺寸下保持可辨识。应用窗口、系统通知、安装包与 Dock 仍使用现有彩色图标。
