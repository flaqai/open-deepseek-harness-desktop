# Agent Note：不重启 Harness 即可恢复工作区浏览区域

Status: implemented

[English](2026-11-06-workspace-region-recovery.md) | 中文

## 问题

工作区槽位渲染失败时，整个浏览区域可能留空，而对话和侧栏控件仍可使用。逐注册项隔离正确保护了兄弟组件，但空白错误节点没有解释或恢复操作。用户报告的运行中故障在重开后消失，无法据此确定触发因素是浏览器状态、插件还是数据更新；仅有 Host 日志也无法取得普通前端异常。

## 决策

侧栏为空工作区槽位提供可见的不可用提示，为失败槽位提供带显式局部重试的错误视图。重试只恢复该槽位单元中符合条件的失败注册，尊重仍存活的注册与卸载状态。它不重启插件、Host 或窗口；再次失败时保持提示，不安排下一次自动重试。其他槽位行为和装配错误保持原有契约。

工作区查看状态通过存储引擎可选的归属方恢复回调验证浏览器 JSON。异常字段独立回退，合法的查看偏好得到保留。恢复记录只含固定原因和字段名，不含原始偏好值或会话内容；只有后续正常操作才持久化恢复后的状态。未提供回调的存储保持整值恢复。

桌面端仅观察当前选中 Harness 主框架发出的工作区槽位错误，限频保存有长度上限、已脱敏的文本和可取得的堆栈；日志失败不会替代应用操作。这为之后的故障补充证据，不代表已经确定此前故障的触发原因。

## 考虑过的替代方案

刷新整个窗口或重启 Harness 会干扰草稿和运行任务。自动重试异常注册可能制造渲染循环。重置整个浏览器存储会丢弃合法偏好，而把所有通用存储与对象默认值合并会破坏标量和数组存储。局部浏览区域恢复均无需这些操作。

## 影响

用户可以在保留当前对话的情况下重试浏览区域。缺失注册时显示不可用说明，不提供无效重试按钮。持续的插件故障仍可能需要修复配置；错误视图不承诺重试能解决所有故障，也不代表缺少的历史记录已被删除。

## 测试

真实槽位账本与渲染器测试覆盖显式恢复、连续失败、注册卸载及兄弟组件保留。侧栏测试覆盖展开、折叠与抽屉表现。存储和 WorkspaceBrowser 测试覆盖损坏或不完整的持久化值。桌面测试覆盖可信框架过滤、凭据脱敏、长度与频率限制及日志写入失败。本次证据不包含 Windows 原生故障复现或浏览器自动化。
