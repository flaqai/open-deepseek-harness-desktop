# Agent Note: 用户可排序的设置导航

Status: implemented

[English](2026-08-30-user-ordered-settings-navigation.md) | 中文

## Problem

设置分区由彼此独立的插件动态贡献。规范注册顺序适合作为默认值，但插件较多时，常用页面可能不方便触达。若用显示文字或数组下标保存偏好，在切换语言或卸载插件时就会失效。

## Decision

设置外壳在长按 350ms 后开始拖动分区和分组，并提供键盘等价操作。跟随浮层、占位、相邻项借位和 180ms 落位动画显示目标位置；减少动态效果偏好会关闭过渡动画。激活前移动保留滚动，Escape 取消且不保存。菜单在悬停或键盘聚焦时显示，触屏设备始终显示；折叠箭头始终可用。分区放置支持排序和跨组移动，分组放置移动整个分组。更改通过有序写入立即保存。写入被拒绝时显示失败并恢复到最后确认的布局，不保留依赖失败写入的乐观修改。标题旁的整理入口负责分组管理和隐藏项恢复，不重复提供排序控件。

Host 持有的 `ui-settings-general.sectionLayout` 设置将稳定的 `settings.section` ID、用户填写的组名、隐藏项目和分组显隐、折叠偏好一起保存。旧分组默认可见且展开。在保存分组布局前，旧 `sectionOrder` 仍作为回退值。隐藏导航项目或分组不会停用插件，也不会阻止显式打开对应页面；即使全部项目都隐藏，整理入口仍可访问。

持久化布局叠加在实时 slot 账本之上，而不修改账本本身。新插件分区追加到默认分组列表，暂时缺失的 ID 保留原分组与隐藏偏好，以便重新安装后恢复。规范化会移除无效和重复 ID。删除分组时，其分区返回默认分组列表；恢复默认只改变导航。

## Alternatives considered

**修改每个插件的注册顺序。** 这会把用户偏好变成共享插件策略，还需要跨越彼此独立的包协调写入。

**保存显示文字或可见下标。** 文字会随语言变化，而每当插件出现或消失时下标都会移动，两种方案都可能静默排错页面。

**使用浏览器本地存储。** 这会绕过既有设置文档，使偏好脱离当前选择的桌面数据目录，并让导入与复用行为和其他 UI 偏好不一致。

## Consequences

用户可以直接整理较长的设置栏、折叠分组，并从同一管理界面恢复隐藏导航。每次有序写入拥有持久化提交点，与插件注册顺序和本地化标签独立。新增状态只有一份版本化布局；规范注册顺序仍是回退值和新注册分区的顺序来源。
