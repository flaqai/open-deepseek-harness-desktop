# Agent Note: 可搜索的模型选择器

Status: implemented

[English](2026-09-16-searchable-model-selector.md) | 中文

## 问题

模型选择器可能包含许多提供方和模型，目视查找速度较慢，名称相似的条目也难以区分。仅按提供方分组无法帮助那些只记得部分模型名称或提供方名称的用户。

## 决策

打开的选择器会在模型列表上方显示一个搜索栏。匹配不区分大小写，覆盖模型名称、模型标识、提供方显示名称和提供方标识。筛选保留提供方分组和现有选中项；没有结果时在选择器内显示本地化提示，关闭选择器会清除临时查询。

选择器打开时，搜索栏会获得焦点。键盘和指针选择继续使用原有模型行；搜索控件不会改变目录顺序、模型身份或选择持久化。

## 曾考虑的替代方案

**仅搜索模型显示名称。** 不予采纳，因为自定义提供方经常暴露不透明的模型标识，而用户可能记得的是提供方或标识，而不是显示标签。

**在多次打开之间保留查询。** 不予采纳，因为查询只是一次选择操作的导航状态，并非模型偏好；重新打开时应显示完整目录。

## 后果

大型目录无需改变来源或顺序即可直接搜索。选择器在所有随附社区语言中增加本地化占位文本和空状态文案，并通过组件测试覆盖匹配、空结果、清除以及从筛选列表中选择模型。
