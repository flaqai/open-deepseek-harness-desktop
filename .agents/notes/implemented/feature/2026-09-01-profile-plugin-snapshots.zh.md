# Agent Note: Profile 插件快照

Status: implemented

[English](2026-09-01-profile-plugin-snapshots.md) | 中文

## 问题

插件隔离与 Profile Doctor 可以在 Harness 可用时恢复能够分类的故障，但插件变更损坏依赖图、诊断界面无法加载，或名义上有效的回退仍导致桌面客户端无法就绪时，它们不能提供已知可用的回退点。复制 `node_modules` 会让快照非常庞大且与平台绑定，而回退整个 `DSH_HOME` 会覆盖无关的会话、凭据、设置和插件业务数据。

## 决策

App Boot 拥有 `dsh/profile-plugin-snapshot/v1`。快照只保存 Web Profile 依赖清单、精确 pnpm 锁文件、workspace 构建策略、隔离记录、预置插件 seed 标记和导入插件恢复状态。元数据记录校验和、脱敏的软件包投影、有序 Bundle、运行时版本，以及引用的本地来源是否已经丢失。它排除已安装模块、pnpm store、用户 Patch、设置、凭据、会话和插件自有数据。

每个会改变状态的 `dsh plugin` 调用都会取得 Profile 变更锁，并创建自动的变更前快照。复制新载荷前，创建逻辑会把受管文件指纹与已保留且载荷校验通过的回退点比较，并复用内容相同的点。新建的自动快照在操作没有改变受管文件时会被删除，复用的旧快照则继续保留。受信任的启动预装会抑制每个插件的自动快照，且不会在应用就绪前创建快照。桌面的两个就绪标记均到达后，当前状态才会替换唯一的 `bootable` 点。只保留最近十个不同的自动状态；手动快照保留到明确删除；恢复事务创建的安全点不能通过普通界面删除。

Desktop 通过闭集、限制输出且最长运行三十秒的 CLI 命令执行快照操作，preload 只投影不透明 id、有限长度名称和明确的联网同意。快照根目录、记录、载荷、受管 Profile 文件和预置 seed 状态在物理路径上必须位于预期根目录中，不能由符号链接替换。恢复会停止 Harness、创建安全点、在第一次修改前校验全部快照载荷、原子恢复受管文件，并让内置 pnpm 执行离线冻结安装。如果缓存材料缺失，Desktop 会先恢复安全点，再提供需要明确确认的联网重试。重启前只读 Doctor 必须通过。只有客户端与事件分发两个就绪标记都到达后才提交恢复；Harness 失败或就绪超时都会恢复安全点并重启原状态。就绪后保留可启动点失败时只记录日志，不会阻断已经健康的应用。

诊断页渲染普通管理卡片，默认只展示最近三个回退点，并提供明确的展开/收起按钮。静态加载页会直接使用同一套窄权限 Electron IPC，因此即使 Host、Remotes、插件清单和主 React 树均无法启动，用户仍能选择回退点。

## 考虑过的替代方案

**归档 `node_modules`。** 否决，因为它会重复数百 MB 数据，保留只适用于一个平台的原生二进制，并绕过 pnpm 完整性和锁文件验证。

**恢复整个 Profile 或 `DSH_HOME`。** 否决，因为 `cordis.patch.yml`、`settings.yaml`、凭据、会话和插件数据不属于插件部署状态，而且可能包含更新的用户工作或秘密。

**从冻结安装自动降级到普通解析。** 否决，因为恢复操作不能静默选择更新的软件包版本。缓存缺失必须单独确认联网，且仍使用精确锁文件。

**在 Harness 输出就绪地址时判定成功。** 否决，因为服务器可能已经监听，但客户端模块或事件分发仍然失败。桌面就绪才是提交边界。

## 后果

用户可以在不丢失对话或配置数据的前提下，对插件栈回归进行有边界的回退；主应用无法渲染时仍有独立恢复入口。registry 与 Git 恢复仍取决于 pnpm store 是否可用，或用户是否明确允许联网。丢失的 `file:`、`link:` 和 workspace 来源会在恢复前显示，且不会被复制到快照中。该功能增加少量本地元数据历史，并让 CLI 与 Desktop 共享一套精确 Profile 变更协议，而不是建立第二个包管理器。

## 验证

App Boot 测试覆盖捕获、差异、精确恢复、自动指纹去重、明确构建拒绝保留、无变化自动清理、安全点保留、修改前校验全部载荷，以及符号链接逃逸拒绝。客户端测试覆盖默认三项列表和展开/收起控件。Desktop 测试覆盖有界单次命令、就绪后快照时机、双就绪标记提交、联网确认前的离线缓存失败回滚，以及启动失败后的自动撤销。Bridge 测试固定渲染器边界。类型检查覆盖 App Boot、CLI、Desktop 和插件清单客户端；Desktop 构建验证加载页资源与打包 preload 路径。
