# Agent Note：桌面 Release 侧栏操作

状态：已实现

[English](2026-09-04-desktop-release-sidebar-action.md) | 中文

## 问题

桌面 Release 发现此前只有打开设置后才能看到。用户停留在主对话界面时可能错过新版本，而开发模拟也只会更新自身所在的设置行。

## 决策

桌面外壳持有一份共享的 Release 呈现状态。新增的 `sidebar.settings.action` list slot 位于“设置”触发器正右侧，不改变上方已有的整行 `sidebar.footer.action` 布局。桌面外壳在该席位注册蓝底白字的更新操作。

该操作仅在存在更新且侧栏展开时渲染，点击后打开通用设置中的更新行。设置面板标题栏操作、侧栏操作和开发模拟读取同一份控制器快照，因此会同步出现和消失。

## 考虑过的替代方案

若把操作放入 `sidebar.footer.action`，它会成为单独的整行，而不是所要求的“设置”旁按钮。无更新时显示禁用或中性占位按钮也被否决，因为它会长期增加视觉噪音，并与客户端为最新时隐藏操作的要求冲突。

## 结果

客户端为最新、正在检查、未启用模拟的开发状态或检查失败时，侧栏不保留可见的更新控件。已有页脚插件保持原有几何。组件测试覆盖真实更新、无更新隐藏、折叠模式、共享模拟和导航，侧栏快照固定相邻席位。
