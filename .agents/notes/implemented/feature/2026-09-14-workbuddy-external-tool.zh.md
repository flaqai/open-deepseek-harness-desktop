# Agent Note：WorkBuddy 保持为显式社区连接

状态：已实现

[English](2026-09-14-workbuddy-external-tool.md) | 中文

## 问题

「外部工具」页面需要在一个位置展示受支持的官方子 Agent Provider 与经过审核的社区模型连接，但不能把第三方代码表示成客户端预置或官方维护。

## 决策

页面在现有工具旁展示 WorkBuddy，并将其标记为社区插件。封闭的界面标识固定映射到经过审核的精确版本 `dsh-workbuddy-connect@0.5.0`，使用受控联网安装器，且不会调用仅供官方 Provider 使用的桌面兼容版本清单解析器。该插件不随客户端预置。用户必须先在本机 WorkBuddy 或 WorkBuddy AI 桌面应用中登录。

Loader 条目处于活动状态只表示插件已就绪。页面不会声称 WorkBuddy 已连接，因为账号就绪状态仍由插件负责。每张工具卡都使用本地、可跟随主题的产品标记，因此设置页面不依赖远程图片传输。

## 考虑过的替代方案

**把社区插件预置进客户端，或将其作为官方 Provider。** 预置会模糊维护归属，并扩大受信任的发行载荷。显式联网安装可让第三方边界保持可见，并复用现有受控插件流程。

## 后果

用户可以发现和安装经过审核的连接插件，且不会把其维护归属与 DeepSeek 官方 Provider 混淆。固定包坐标使每次版本更新都成为显式客户端审核。本集成不修改任何第三方源码，也不会取得受控插件安装器以外的新权限。
