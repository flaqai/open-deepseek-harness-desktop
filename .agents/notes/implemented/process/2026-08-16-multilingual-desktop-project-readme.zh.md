# Agent Note: 多语言桌面项目 README

Status: implemented

[English](2026-08-16-multilingual-desktop-project-readme.md) | 中文

## 问题

下游仓库在 DeepSeek Harness 之上增加了桌面宿主，以及面向产品的配置、会话、主题、插件、Skill 和源码更新界面。原先以上游为中心的根 README 没有明确标识这一发行版，也未向国际用户稳定说明已实现能力、平台限制、安全模型及其与可选提供商的关系。

## 决策

根 README 将 Open DeepSeek Harness Desktop 表述为社区独立维护的 MIT 发行版，指明官方上游，同时不暗示背书关系。英文和简体中文继续作为完整且同等权威的配对文档。另设十三个本地化 README 入口，提供翻译后的项目概览、源码运行说明、准确的平台状态、文档入口、可选的 FLAQ.AI 背景说明，以及返回完整配对文档的链接。

每种语言入口使用相同的十五语言切换栏。完整 README 区分已经实现的桌面行为与发布方向，将详细行为链接到其归属文档，并收窄平台声明：macOS 源码运行已经过验证，而 Windows 和 Linux 安装包仍需完成打包和原生验证。提供商说明明确指出兼容服务属于可选项，使用前需要核对当前兼容性与政策，且不代表 DeepSeek 背书。

此决策部分取代[产品优先 README 说明](2026-07-22-product-first-root-readme.zh.md)中保留根文档原有结构的要求。该说明继续负责产品优先的范围、简洁清单和每项细节仅保留一个归属位置的政策。

## 考虑过的替代方案

**将完整长篇 README 翻译成每种语言。** 完全一致能提供更多本地化细节，但也会成倍扩大快速变化的预览期行为的维护范围。简洁的本地化入口负责项目发现，英文和简体中文则保持一组完整且经过评审的文档。

**仅保留英文和简体中文。** 这样维护成本最低，但无法为语言切换栏所覆盖的社区提供可直接使用的首页。

**复制参考指南的文案与媒体。** 复用会模糊项目归属，并带来许可证和内容时效方面的义务。本仓库只参考其导航思路，所有事实文案均依据本地实现及其归属文档重新编写。

## 结果

读者可以在安装前识别下游桌面项目、当前支持边界和扩展方向。能力、启动命令、平台支持、安全或提供商关系变化时，先更新完整的英文和简体中文配对文档；本地化入口所概括的事实变化时再同步更新。增加其他语言不会削弱仓库强制执行的中英文配对门禁。
