# 设置导航布局

[English](guide.md) | 中文

## 变更

`ui-settings-general.sectionLayout` 偏好从版本 1 的分组成员变为版本 2 的有序独立项和分组。旧客户端无法读取版本 2。会话历史、插件启停和凭据不受影响。

## 迁移

1. 使用新客户端调整导航之前备份 Profile 配置。读取已有版本 1 值不会覆写配置；未分组项在原位置展开，折叠的成员也会保留。
2. 正常整理设置。首次成功保存布局时写入版本 2。确认独立项和自定义分组顺序正确，并检查隐藏项恢复。
3. 返回旧客户端前恢复备份的 `sectionLayout` 值。不要让旧客户端读取版本 2 偏好，也不要通过移除插件配置修复导航。
