# @deepseek-ai/dsh-client-ui-selection-actions

[English](README.md) | 中文

## 概述

本包为显式对话范围内选中的文字提供面向桌面端的“复制”“在新对话询问”“在侧边对话中询问”和“添加到对话”操作。在 Electron 中，右键菜单底部还会显示“快速重启”，并通过桌面端受保护的生命周期执行；普通浏览器不提供此项。它在弹层获取焦点前捕获不可变文字，且绝不自动发送草稿。

<a id="use-the-selection-actions"></a>
## 使用选中文字操作

右键点击有效选区会打开共享 `Menu contextual` 菜单，统一操作行、图标、禁用状态、分隔线、阴影和材质。指针激活保留选中文字，定位继续由官方文本交互浮层负责。主键划选继续由官方引用操作负责。所有对话操作都向目标输入框插入官方原子引用，不会提交，并保留已有文字和引用卡片。“添加到对话”以产生选区的对话为目标。受信任的 Electron preload 提供受限重启能力时，菜单底部会在分隔线后显示“快速重启”；浏览器模式不会显示它。

<a id="understand-the-safety-boundary"></a>
## 安全边界

菜单使用官方对话文本交互注册表及会话作用域的 keyed surface。Chat 视图负责选区资格、定位和关闭；输入框、编辑器、控件、设置和侧边栏中的非对话控件不参与。草稿操作遵循选中对话的身份及当前访问权限。

“在侧边对话中询问”在源工作区创建普通会话，并使用官方嵌入式 Conversation 布局在操作时捕获的父侧栏中打开。它不会创建或冒充子代理。资源持有会话引用直到标签关闭；恢复标签时打开已有会话，不会再次插入引用。

操作反馈由独立的 shell overlay 承载，因此复制和草稿错误在对话弹层关闭后仍可见。本包不另外安装 document 级指针或右键菜单监听；共享 Menu 负责菜单键盘和关闭行为。执行操作时会再次检查创建和引用权限。侧边打开失败会释放引用并关闭本次新标签，绝不删除会话数据，因此已创建的空会话可能保留以供恢复。

<a id="model-experience"></a>
## 模型体验

无，因为浏览器端草稿控件会让选中文字保持在模型上下文之外，直到人类提交生成的草稿。

#### KV Cache 影响

无；本包既不组装也不发送提供方请求。

## 已知限制与后续工作

<a id="known-limitations-and-deferred-work"></a>

- 暂不处理触摸长按划选；首版面向鼠标和触控板交互。
- 在出现明确的扩展使用方和权限模型前，操作列表保持固定。
