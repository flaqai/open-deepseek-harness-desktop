# Windows 安装记录修复

[English](README.md) | 中文

## 概要

在程序目录被手动删除后，修复本应用残留的 Windows 安装记录。工具支持经过核验的任意本地安装路径，以及当前用户和所有用户两种安装范围；不删除程序文件、配置、历史或 PATH 条目。

## 修复已删除的安装

开始前请关闭所有 Open DeepSeek Harness Desktop 安装程序。在受影响的 Windows 账户下使用 64 位 Windows PowerShell。若旧程序目录仍存在，请使用正常卸载程序；本工具会拒绝清除它的注册记录。

1. 从仓库获取本文件夹，或在包含该工具的 Windows 构建中打开程序目录下的 `resources/support/windows-install-repair/`。若下载的是压缩包，请先选择**全部解压缩**。
2. 若原安装选择**仅为我安装**，请在原 Windows 账户下双击 `START-REPAIR.cmd`。若原安装选择**为所有用户安装**，请明确对 `START-ALL-USERS-REPAIR.cmd` 选择**以管理员身份运行**；工具不会自行提权。
3. 核对确认框中的安装范围、旧目录和备份位置。默认选择为**否**。仅在这些信息对应待修复的已删除安装时确认。
4. 修复完成后重新运行安装程序。若出现错误，请保留完整提示和显示的备份目录，以便诊断。

每个启动器均内嵌完整 PowerShell 内容，不依赖相邻的 `.ps1` 文件。当前用户修复只检查当前账户的 `HKCU`；所有用户修复只检查 `HKLM`。两种模式均不会加载其他用户的注册表，也不会修改另一安装范围。

## 安全与诊断

工具仅检查本发行版固定的应用注册项，要求应用身份、版本元数据、目录和卸载范围一致。磁盘不可用、路径访问被拒绝、重解析点、注册信息发生变化或程序目录仍存在时，工具会停止，不会把这些情况当作安装已删除。

删除任何记录前，工具先备份全部待处理注册项，并重新核对记录状态。备份与 `repair-result.json` 保存在 `%LOCALAPPDATA%\OpenDSH-Repair` 下每次运行独立的目录中。删除失败时，恢复不会覆盖并发重新创建的记录；无法确认恢复成功时，请保留备份和错误信息。成功重新安装后，不要导入旧注册表备份。

本工具不修复插件错误，也不卸载仍存在的应用。它不删除快捷方式、用户数据、无关应用或其他账户的记录。遇到含糊记录时会停止，不猜测安装路径。

## 源码与验证

仓库中可阅读的入口为 `tools/windows-install-repair/repair.ps1`，它会从完整仓库中加载共享注册模块。同目录中的 `generate-launchers.mjs` 将这些源码合成为两个独立启动器；打包时会检查启动器与源码是否一致。程序包内的支持工具目录只包含启动器和本说明，不携带仓库的源码依赖。

PowerShell 行为测试覆盖检查、确认、备份、失败和安装范围处理。发布 Windows 候选包前仍须完成原生 Windows 安装、注册表修复与卸载验收；可移植测试与 NSIS 编译本身不能代替该验收。
